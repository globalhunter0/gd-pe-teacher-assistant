# v0.29.0 体育测试与评分 V1.0 阻断项修复报告

验收日期：2026-09-25。范围：现有初中体育测试、城市评分及初中国家体测业务。采用用户正式确认的长跑 MMSS 规则；不迁移历史成绩，不 push。

## 1. 原始成绩覆盖

普通编辑器记录实际修改过的成绩行，仅这些行进入解析和评分。修改标题、备注或保存未改动记录不会重新解析原成绩。快速录入未修改输入直接确认时跳过重算；显式重新输入才应用新规则。保存失败保留编辑内容，重复点击受同步锁保护。

## 2. Excel 单位

统一识别项目单位、表头单位和输入中的显式单位，按项目要求转换米/厘米等单位。不兼容单位报错。明确的秒、总秒数、seconds 优先于长跑快捷推断；不靠猜测或补零接受含糊的小数输入。

## 3. 三个入口一致性

普通录入经 applyPeTestEdits 调用快速录入应用逻辑；快速录入和 Excel 共用项目感知 measurement 解析以及评分路径。原始文本保留在 rawOriginal，持久化 rawValue 使用项目标准单位。回归覆盖三个入口及真实 XLSX 读入、入库和历史导出往返。

## 4. 学生身份

导入校验班级、年级、学号、姓名、性别和可选 studentId/classId；同名、跨班学号及冲突身份不猜配。主进程再次校验新增成绩身份和历史快照，事务执行前检测学生、班级、项目与测试集合变化。课堂来源继续使用原课堂名单快照。

## 5. 800m / 1000m 规则

- 裸输入 342、3.42、3:42 均为 222 秒；315、405、430、512 分别为 195、245、270、312 秒。
- MMSS 最后两位必须是 00–59；375 拒绝，不进位为 4:15。
- 342秒，或总秒单位列中的 342，为 342 秒。
- 3.05 / 3:05 为 185 秒，不作为小数分钟。
- 50m 的 8、8.1、8.25 仍是秒，不使用长跑 MMSS。
- 男生 1000m、女生 800m 按实际项目评分；未知或不适用性别不评分。

## 6. 完整评分字段

Excel 与手工录入共同产生适用的 examScore、baseScore、bonusScore、scoreOutcome、officialMinimumScore、实际项目和评分依据快照。导入计划按当前明确依据核验预览结果，拒绝被篡改或失效的分数。身高、体重保留原始测量值，不伪造独立分数。

## 7. 历史保护

不运行批量重解释或迁移。历史 rawValue=342 保持 342；更改学生性别、班级或评分标准不会修改已有成绩。历史身份及评分依据不能通过普通保存改变。显式编辑单条成绩时才重新解析、评分；并通过预期版本比较拒绝过期覆盖。

## 8. 未识别 Excel 项目

未知或歧义项目列产生明确待处理/错误记录，不默默丢弃。统计区分成功、错误、状态记录及有原因的跳过；“9 项成功、1 项未知”仍报告失败，不能作为全部成功提交。

## 9. 初中国家体测范围

支持初一、初二、初三，依据现有国家体测引擎和性别项目规则处理身高、体重、BMI、肺活量、50m、坐位体前屈、立定跳远、男生引体向上/1000m、女生仰卧起坐/800m。导入提供明确初中年级选择，目标班级年级不一致时阻止。未扩展小学和高中导入。

## 10. BMI

增加 BMI 项目，接入现有国家体测 BMI 评分。支持直接 BMI 列，以及由有效身高/体重推导 BMI；直接 BMI 优先。推导结果保留为 BMI 成绩，源身高/体重同时保留。覆盖导入、评分、保存及历史导出。

## 11. 缺考 / 免考 / 未测

A、a、absent、缺考/缺测统一为缺考；exempt、免考/免测为免考；pending、未测及空输入为未测。这些状态不写成 0 分，不参与有效成绩均值、分档和趋势；历史异常残留分数也不会作为有效成绩展示或统计。

## 12. 重复导入

按测试业务身份检测已存在及同批重复记录，组合长跑与拆分 800m/1000m 相互识别。重复、冲突和跳过有明确结果，不无提示覆盖。继续使用既有暂存事务写入，回归验证失败时原磁盘数据不变。

## 13. 历史页面与导出

读取已保存 rawValue、状态、分数和快照，不从 rawOriginal 重新解析。成绩文本共用状态处理，非有效成绩显示为无分数；班级显示使用测试快照。包含真实 XLSX 内存往返验证。
