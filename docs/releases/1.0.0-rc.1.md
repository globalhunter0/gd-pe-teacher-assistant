# 广东省初中体育教师管理助手 1.0.0-rc.1

本版本为小范围测试版（Release Candidate），供 1～3 名可信任体育教师试用，尚非正式稳定版。

## 可以试用的功能

- 班级与学生管理、Excel 学生导入。
- 课表管理、工作台、课堂记录，以及考勤、表现标签和备注。
- 教学计划。
- 体育测试、Excel 体育成绩导入、自动评分、800m / 1000m 成绩录入。
- 国家体质健康测试初中范围、BMI、成绩历史和 Excel 导出。
- 训练队、资料中心及附件。
- 备份与恢复。

AI 助手暂未开放，后续版本提供。

## 试用提示

这是 RC 测试版本，建议重要数据定期备份；安装或升级前，请先在“备份与恢复”中保存一份备份，并保留原安装包。试用遇到问题时，请记录应用版本、操作步骤和提示内容，反馈时避免提供学生个人信息。

升级时请先关闭应用，再运行新安装包。卸载默认保留业务数据。若需退回旧版，请先备份当前数据，再联系试用负责人核对旧版安装包和对应备份；本轮不保证旧版能读取所有后续版本的数据。

当前小范围测试版尚未配置 Windows 商业代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。请核对安装包来源和随包提供的 SHA-256；无需关闭 Windows 安全防护。
