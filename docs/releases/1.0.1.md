# 广东省体育教师管理助手 1.0.1

## 新增：大单元教学设计（AI）

入口：教学计划 → “大单元教学设计（AI）”。

- **教材目录**：内置义务教育 10 个、普通高中 7 个审定版《体育与健康》教材及教师用书分册，新建大单元时按年级筛选版本，并按运动项目提示对应的教师用书分册。
- **课标要求**：依据《义务教育体育与健康课程标准（2022年版2025年修订）》与《普通高中体育与健康课程标准（2017年版2025年修订）》，内置课程内容类别、水平划分、大单元课时下限（不少于 18 课时）与运动负荷要求（群体运动密度≥75%、个体运动密度≥50%、平均心率 140～160 次/分、每节课体能练习约 10 分钟）。
- **三级生成**：大单元教学计划 → 单元教学计划（含逐课次安排）→ 课时教案。课时教案可单节生成，也可批量生成，生成过程中可随时取消。
- **广州市统一课时教案模板**：在应用内按模板表格编辑课时教案，包括教学目标（运动能力、健康行为、体育品德）、教学内容、安全预案（高中为“安全防范措施”）、重点、难点、教学流程、开始/准备/基本/结束各部分、预计运动负荷、场地器材和教学反思。
- **课标检查**：大单元、单元和课时教案实时显示“不符合”和“提醒”项，例如各部分时间合计、运动密度、心率区间、体能练习时长，以及是否安排比赛。
- **导出 Word**：大单元（连同各单元计划）和课时教案都可以导出为 .docx。
- **参考资料**：可从资料中心选择教师自己导入的教材或教参（txt、md、docx、pdf），生成时会优先依据资料中的相关内容。

## 使用前设置

在“备份与恢复”页的“大模型”卡片中选择服务商（DeepSeek、硅基流动、通义千问、Kimi、智谱、豆包、OpenAI 或自定义 OpenAI 兼容接口），填写 API Key 后点“测试连接”。硅基流动支持切换深度思考；生成长篇结构化教学设计时默认关闭，以减少等待时间和费用。长篇生成采用流式接收，只在连续无响应达到超时时间时中止。

- API Key 经系统加密保存在本机，不会写入备份文件，也不会显示在界面上。
- 生成内容只是草稿，教师审核修改后再使用；重新生成会覆盖原内容，但已写的教学反思会保留。

## 数据与兼容

- 教学设计保存在 `teaching-designs.json` 中，已纳入备份与恢复和数据完整性检查。
- 恢复旧版备份时，现有教学设计会保留。
- 从 1.0.0 升级不会改动任何已有数据。
