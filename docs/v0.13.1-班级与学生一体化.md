# v0.13.1 班级与学生一体化（下一阶段，尚未实现）

本文件只记录设计目标。不在 v0.13.0 实现。

## 目标

把界面上的「班级管理」和「学生管理」整合成「班级与学生」。

数据实体保持独立：

- `ClassRecord` 仍是行政班
- `Student` 仍是学生，继续通过 `studentId` / `classId` 关联班级
- 不把训练队并入此模块

## Excel 导入

- 首次导入：可根据班级字段自动创建尚不存在的班级
- 已有班级再次导入：执行名单 diff
- 显示：保留 / 新增 / 移出名单 / 冲突
- 用户确认后，以最新 Excel 作为该班当前 `active` 学生名单
- 新名单中不存在的旧学生不得物理删除
- 有历史记录必须保留
- 通过既有 `status` / 转出等语义处理
- 有 `studentNo` 时优先按班内学号匹配
- 无学号或身份不明确时，不得危险自动合并

## 人数

- 真实 `active` 学生数动态显示
- 原 `ClassRecord.studentCount` 暂时继续保留手工语义，不在本阶段改成自动覆盖
