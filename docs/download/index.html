安装步骤

  1. 确认电脑是 Windows 10 或 Windows 11，64 位。完整版目前仅 Windows；手机可用免费网页版查标准与录入。
  2. 下载完成后，打开文件：gd-pe-teacher-assistant-1.0.0-Windows-x64-setup.exe。
  3. 如果弹出「Windows 已保护你的电脑」，先点「更多信息」，再点「仍要运行」。这是因为安装包还没有购买 Windows 数字签名，不是病毒提示本身。
  4. 按提示完成安装。这是当前用户安装，一般不需要管理员密码。
  5. 安装结束后不会自动打开。到桌面或开始菜单找到 gd-pe-teacher-assistant，点开即可。窗口标题是「广东省初中体育教师管理助手」。
  6. 第一次使用建议先到「设置」做一次备份，备份包自己保存。
  7. 以后有新版本，打开软件后到「设置 → 检查更新」，不必反复重装。
