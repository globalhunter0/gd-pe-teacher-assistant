====================
私信模板 · 现用（GitHub 发货页）
====================
付款收到。这是 Windows 安装包和安装说明。

请用电脑浏览器打开这个链接，打开后会自动开始下载：
https://globalhunter0.github.io/gd-pe-teacher-assistant/

安装步骤：
1. 电脑需 Windows 10/11 64 位。完整版是 Windows；手机可用免费网页版（查标准/录入）：
   https://globalhunter0.github.io/gd-pe-teacher-assistant/mobile/
2. 下载约 179MB，文件名是 gd-pe-teacher-assistant-1.0.2-Windows-x64-setup.exe。
3. 双击运行。若弹出“Windows 已保护你的电脑”，点「更多信息」→「仍要运行」。
4. 按提示安装，一般不需要管理员密码。
5. 安装完不会自动打开。到桌面或开始菜单点 gd-pe-teacher-assistant。
6. 建议先到「设置」做一次备份；也可「导出手机同步包」给网页版用。
7. 以后有更新，打开软件后到「设置 → 检查更新」。

这不是教育局/学校官方系统，数据保存在你这台电脑，不强制注册。
当前 v1.0.2，也不承诺提高体育中考分数。
安装遇到问题，把截图发我。

====================
你怎么生成网盘链接（约 2 分钟）
====================
1. 打开夸克网盘（推荐，约 179MB，微信里也比较好打开）。
2. 新建文件夹：广东省初中体育教师管理助手-v1.0.2
3. 把这两个文件传进去：
   - 安装包：gd-pe-teacher-assistant-1.0.2-Windows-x64-setup.exe
     （从上面的 GitHub 直链下载，或从本机 release 目录取）
   - 说明：docs/download/网盘发货/请先看我-安装说明.txt
4. 分享这个文件夹：有链接即可访问，有效期选永久。
   个人售卖建议开提取码，避免链接被转发白嫖。
5. 复制分享链接和提取码，替换上面「网盘版」模板里的两行。
6. 自己先用另一台电脑或无痕窗口点开，确认能下到 exe、说明文字能打开。

不要上传 .exe.blockmap、latest.yml、源码、Token、仓库登录方式。
